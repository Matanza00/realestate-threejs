# From Ground to Home

Scroll-driven, interactive Three.js real estate experience. Scroll from an empty plot at
dawn to a finished building at night, at human eye level.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
npm run log:export # save the latest Claude Code conversation to context/log/
```

Project history, decisions and next steps: [`context/PROJECT_CONTEXT.md`](context/PROJECT_CONTEXT.md).
How Claude Code and Claude Chat stay in sync: [`context/README.md`](context/README.md).
